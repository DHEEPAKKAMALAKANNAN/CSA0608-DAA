3) Why the subtractive variant: additive vs subtractive Karatsuba on random 64-digit pairs
   Both use the schoolbook base case n <= 3 (the additive variant needs it: for n <= 3 its middle
   operands a0 + a1 have m + 1 >= n digits, so the problem would not shrink).
   Predicted subtractive count: M(64) = 3^5 * M(2) = 243 * 4 = 972
   pair 1: additive mults = 2,004   subtractive mults =   972   both correct: True
   pair 2: additive mults = 1,880   subtractive mults =   972   both correct: True
   pair 3: additive mults = 1,992   subtractive mults =   972   both correct: True
   pair 4: additive mults = 2,023   subtractive mults =   972   both correct: True
   all-nines operands (a carry at every level): additive mults = 2,291  -> the additive count depends on the data
